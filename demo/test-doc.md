# Spring AI 使用说明

Spring AI 是 Spring 官方推出的 AI 应用开发框架，核心目标是提供统一的抽象层，
让开发者可以在不同的大模型服务商之间切换，而不需要修改业务代码。

## 核心抽象

ChatClient 是对对话模型的封装，支持流式和非流式调用。
EmbeddingModel 负责把文本转成向量，是所有 RAG 应用的基础。
VectorStore 是向量数据库的统一接口，Chroma、Milvus、PgVector 都是它的实现。

## 检索增强生成

RAG 的核心思路是把文档切块、向量化后存入向量库。
用户提问时，先把问题向量化，再从向量库里找出最相似的几个片段，
拼进 Prompt 一起交给大模型，让模型基于真实资料回答，减少幻觉。
